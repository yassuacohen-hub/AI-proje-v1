Landing page uretimi bu cerceve + `docs/brand/brand.md` + `design-tokens.json` ile yapilir.

## Hero (sabit)
- Marka: Huginn & Muninn
- Slogan: Map the Innovation Economy
- Alt metin: Discover startups, founders, companies, investors, and market opportunities through a modern intelligence platform.
- Primary CTA: Start Exploring - Secondary CTA: Book a Demo

## Gorsel sistem
- Tema: dark-first - taban `#09111F`, ikincil yuzey `#131C2F`, metin `#FFFFFF`, ikincil metin `#94A3B8`
- Hero gradyan: `#2563FF -> #7C3AED -> #22D3EE` (tokens: gradients.hero); kart golgesi `shadow.hero`
- Radius: `md 12px` / `lg 18px` / `xl 24px`; spacing olcegi tokens'tan
- Tipografi: modern geometric sans-serif (brand.md onerileri; token sabitlemesi roo onayi sonrasi)

## Ton ve yasaklar
- Premium B2B SaaS, VC estetigi, Scandinavian minimalism, data-first
- Yasak motifler: kus/raven, kanat, kalkan, kure, buyutec, harita, siber guvenlik klisesi, hacker estetigi
- Ek mesajlar (serbest kullanim): "Discover tomorrow's winners." / "Intelligence for builders." / "See opportunities before others."
