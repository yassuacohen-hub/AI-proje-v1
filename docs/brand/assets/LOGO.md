## Birincil Prompt (guncel - Muninn icon-only, 2026-09-26)
Create a world-class technology logo icon for an AI platform called Muninn.

IMPORTANT:
- Icon only
- No text
- No typography
- No words
- No mockups
- Transparent background
- Single centered symbol

Design Direction:

Create a highly recognizable abstract symbol inspired by the letter M but not literally drawn as a letter.

The icon should consist of sharp geometric forms creating a futuristic angular structure.

Use negative space and intersecting shapes to suggest:

- Intelligence
- Memory
- Discovery
- Knowledge
- AI reasoning
- Data mapping
- Network analysis

Design Language:

- Premium SaaS branding
- Enterprise software
- Stripe-level simplicity
- Linear.app precision
- Vercel minimalism
- Raycast icon quality

Structure:

- Two angular wings converging toward center
- Abstract folded geometry
- Balanced symmetry
- Clean silhouette
- Small intelligence node connected by a diagonal element
- Node positioned near the upper-right area
- Strong shape recognition even at 24x24 pixels

Appearance:

- Modern
- Minimal
- Flat vector
- Scalable
- SVG-friendly
- Geometric
- Professional

Color Palette:

Primary Gradient:

Start:
#1FD6FF (Electric Cyan)

Mid:
#2979FF (Intelligent Blue)

Transition:
#4F46E5 (Indigo)

End:
#8B3DFF (Violet)

Accent Highlights:

#63E6FF
#5A8CFF

Deep Shadow Color (very subtle if needed):

#172554

Background:

Transparent

Restrictions:

- No glow
- No shadow effects
- No 3D rendering
- No glassmorphism
- No bevels
- No excessive detail
- No bird illustration
- No raven drawing
- No mascots
- No circles except the single node
- No text elements

Output:

- Premium vector icon
- Transparent PNG
- SVG style
- High contrast
- Perfect favicon visibility
- Perfect admin dashboard branding
- Modern AI startup identity

## Eski Prompt (arşiv - Huginn & Muninn ortak icon, öncesi)
Create an award-winning icon-only logo for a Startup Intelligence Platform called Huginn & Muninn.
Design a bold geometric symbol built from two angular structures connected by a diagonal pathway.
The symbol should subtly form an abstract "M" shape while remaining highly recognizable as an independent icon.
At the top of the diagonal connection place a single circular node representing:
- startups / innovation signals / founders / opportunities / investments

Style: premium SaaS branding, enterprise-grade, geometric precision, sharp angular vector shapes,
high contrast silhouette, no gradients required but allowed for depth, transparent background,
scalable vector quality, works at 16x16 favicon size.

Composition: single unified icon, no separate letterforms, no wordmark, strong negative space use,
balanced symmetry, modern tech aesthetic.

Color palette: deep navy (#09111F), electric blue (#2563FF), vibrant indigo (#4F46E5),
subtle cyan accent (#22D3EE), transparent background.

Avoid: birds, ravens, wings, shields, globes, magnifying glasses, maps, cybersecurity imagery,
hacker aesthetics, mascots, illustrations, text, wordmarks, drop shadows, 3D bevels, glassmorphism.

Brand Inspiration: Stripe, Linear, Vercel, PitchBook, Crunchbase, Palantir - clean, confident,
data-intelligence aesthetic without being generic fintech.
