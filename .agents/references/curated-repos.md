## 🚀 2. Gelecekte Eklenebilecek Özel Beceriler (Domain Skills)

İhtiyaç duyduğumuzda `.agents/skills/` altına ekleyebileceğimiz özel beceri modülleri:

1. **`fastapi-clean-architecture`:** Python & FastAPI ile REST API geliştirme standartları.
2. **`react-nextjs-tailwind`:** Modern frontend, component yapısı ve durum yönetimi (state management).
3. **`docker-and-cloudrun`:** Dockerfile optimizasyonu ve Google Cloud Run deployment iş akışları.
4. **`rag-and-llm-pipeline`:** Vektör veritabanları (Chroma, Pinecone) ve LLM zincirleri geliştirme rehberi.
