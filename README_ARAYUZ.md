# Ankara B2B Company Master — Arayüz

## Çalıştırma

```bash
pip install streamlit pandas
streamlit run app.py
```

Ardından tarayıcıda: `http://localhost:8501`

## Ekran Görüntüsü (Planlanan)

- **Dashboard:** OSB dağılımı, sektör istatistikleri
- **Firmalar:** Örnek tablo, filtre
- **Cross-Source:** 6 veri kaynağı durumu
- **Wiki:** Proje dökümanlarına link

## Ne Zaman Gerçek Veri?

- Şu an: **örnek veri** (3 firma)
- Faz 1A: OSTİM 300 firma (1 sayfa)
- Faz 1B: 6.500+ firma (tüm OSTİM)
- Faz 2: 16.810+ (3 OSB)
