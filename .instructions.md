# VS Code Copilot Instructions - AI Proje v1

Bu dosya GitHub Copilot'a proje bağlamında nasıl çalışması gerektiğini anlatır.

## 🎯 Temel İlkeler

### 1. Skill-Based Development
Tüm geliştirme aşağıdaki skill'lere dayanır:
- **enterprise-data-classification:** PII/DLP tespit ve sınıflandırma
- **data-designer-synthetic:** Sentetik veri üretimi (KVKK/GDPR uyumlu)
- **data-quality-testing:** Veri kalitesi validation ve test kuralları
- **code-quality-and-security:** Tip güvenliği ve hata yönetimi
- **interactive-mentor:** Türkçe mentorluk ve açıklayıcı yaklaşım

### 2. Açıklamalı Geliştirme (Mentorship First)
- Hiçbir zaman sessiz kod üretme; her kod parçasının **neden** ve **nasıl** çalıştığını Türkçe açıkla
- Yazılım kalıplarını (Design Pattern) belirt
- Kütüphane seçim kararlarını gerekçelen

### 3. Tip Güvenliği & Hata Yönetimi
- Type Hints: Her fonksiyon parametresi ve dönüş değeri için type annotation zorunlu
- Hatalar asla sessizce yutulmaz; anlamlı exception handling ve loglama
- `except: pass` veya `except Exception: pass` kesinlikle yapılmaz

### 4. Modüler Mimari
- Single Responsibility Principle (SRP) uygulanır
- Her modul tek bir sorumluluğa sahip: 
  - `classifier/` → PII tespit
  - `designer/` → Sentetik veri
  - `validator/` → Kalite kuralları
  - `services/` → Dış entegrasyonlar

## 🧪 Test Yönetimi

### Test Çalıştırma
```bash
python run_tests.py
```

### Rapor Formatları
- JSON: `test_reports/{timestamp}/test_results.json`
- HTML: `test_reports/{timestamp}/test_results.html`
- TXT: `test_reports/{timestamp}/test_results.txt`
- Özet: `test_reports/summary.json`

### Test Gereksinimi
- Her yeni özellik için birim test yazılmalı
- Test coverage > 80% hedeflenmelidir
- Tüm testler geçmeden kod merge edilmez

## 🔐 Güvenlik & Privacy

### Hassas Veri Yönetimi
- Gerçek test verisi hiçbir zaman hardcode edilmez
- Tüm PII mock/sentetik veri ile üretilir
- API anahtarları ve parolalar `.env` veya environment variables'da

### Desteklenen PII Türleri
```python
- TCKN (T.C. Kimlik Numarası)
- Kredi Kartı (Luhn kontrolü)
- IBAN (Uluslararası hesap numarası)
- Email (RFC 5322)
- Telefon (Türkiye & Uluslararası)
- Passport (Yeni)
- Ehliyet (Yeni)
```

## 🚀 Geliştirme Workflow

1. **Planlama**: V10/07-Tasks altında görev oluştur
2. **Tasarım**: Mimari değişiklik gerekirse V10/02-Architecture güncelle
